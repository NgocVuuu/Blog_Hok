Season Game Mode Adjustments

Balance Adjustments

We have taken note of player feedback about Spriteling Troop, especially issues affecting battle experience, such as extreme engage scenarios and excessive shielding.

To address this, we plan to remove Plant Flag's Speed Up effect, and reduce the shield granted after planting the flag.

1. Removed the brief burst of Movement Speed that diminishes over time after planting the flag.

2. Reduced the shield based on the number of teammates.



Fixes and Improvements

1. Fixed an issue where the flag displayed abnormally under certain conditions after Spriteling planted the flag.

2. Fixed an issue where the Icy Charms trail displayed abnormally.

3. Fixed an issue where Haya could occasionally pull targets hit by Cirrus's Ultimate into the mirage.

4. Improved the trail animation of True Hertz Yaria when leaving base in-match.

5. Improved the sound effects of Crimson Rider Guan Yu's enhanced Basic Attack while in Charge Stance.

6. Fixed an issue where the skin quality label displayed at an incorrect layer when scrolling up or down in edit mode on the Skin Display page.

7. Fixed an issue where tapping Ballerina Erin's Custom Button, Love Dance, would display an excessively large effect.

8. Fixed an issue where Cirrus could not take flight after leveling up directly from level 3 to level 5 in quick match mode.
