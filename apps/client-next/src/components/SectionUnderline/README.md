# SectionUnderline Component

## Mô tả
Component trang trí gạch dưới cho các section title với animation.

## Features
- Customizable width and color
- Optional diamond decoration
- Animation support

## Usage
```tsx
import SectionUnderline from '@/components/SectionUnderline';

<SectionUnderline 
  width={60} 
  color="#FFD700" 
  diamond={true}
  animated={true}
/>
```
