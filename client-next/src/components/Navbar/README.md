# Navbar Component

## Mô tả
Component navigation bar chính của ứng dụng, hỗ trợ responsive design với mobile drawer.

## Features
- Responsive design (desktop/mobile)
- Scroll-based shrinking effect
- Multi-language support
- Mobile drawer menu
- Active route highlighting
- Smooth animations

## Files
- `index.tsx` - Main component
- `Navbar.css` - Styling

## Dependencies
- Material-UI (AppBar, Toolbar, Menu, Drawer)
- Next.js (Link, usePathname)
- react-i18next (translations)
- react-icons/md (icons)

## Usage
```tsx
import Navbar from '@/components/Navbar';

<Navbar />
```
