# LazyImage Component

## Mô tả
Component image với lazy loading và placeholder, tối ưu hiệu suất.

## Features
- Lazy loading
- Placeholder support
- Error handling
- Responsive

## Usage
```tsx
import LazyImage from '@/components/LazyImage';

<LazyImage 
  src="/path/to/image.jpg" 
  alt="Description"
  width={300}
  height={200}
/>
```
